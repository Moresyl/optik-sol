# optik-debug

Optik is a mobile-first in-page developer console for debugging real devices and WebViews.

## Install

```bash
npm install optik-debug
```

```ts
import { mount } from 'optik-debug';

const optik = mount();
```

For direct browser use, the global build mounts automatically:

```html
<script src="https://unpkg.com/optik-debug"></script>
```

See the [GitHub repository](https://github.com/Moresyl/optik#readme) for usage, API documentation, development instructions, and the security policy.
